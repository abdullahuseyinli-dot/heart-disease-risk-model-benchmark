# Heart outer v4 failure

MIRRAMS v4 fixed all shard-level predictions and adaptation decisions, joined the
canonical endpoints, and then failed before writing metrics because a broad glob
mixed labelled and endpoint-free shard files. PS-MaskDRO v4 was not launched into
the known defect. No v4 heart result is claimed.

The exact failure and no-refit v5 recovery are documented in
[the v4 failure record](OUTER_V4_FAILURE_AND_V5_RECOVERY.md).
